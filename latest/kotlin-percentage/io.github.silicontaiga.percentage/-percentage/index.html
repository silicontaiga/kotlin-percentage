Percentage

class Percentage : Comparable<Percentage> (source)

A quantity expressed per hundred: 50%.

The value carried is the ratio — fifty percent is 0.5. Every other scale is a named factory going in and an accessor of the same name coming out, so no number crosses this boundary without saying which scale it is on.

Instances are immutable and thread-safe.
